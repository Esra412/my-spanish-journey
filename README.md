# my-spanish-journey
My internship journey in Spain, sharing my IT experiences, daily life, and unforgettable memories.

## Publish with GitHub Pages

The website is a flat static site in the repository root: `index.html`, `style.css`, `app.js`, `content.js`, `translations.js`, and its images. The Pages workflow packages and publishes these site files when changes are pushed to `main`.

In the repository settings, open **Settings → Pages** and set **Build and deployment → Source** to **GitHub Actions**. Then push or merge the workflow to `main`; the deployment status and site URL will appear under the repository’s **Actions** tab.
